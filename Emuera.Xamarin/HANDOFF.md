## 关键决策

- **Rikaichan 移植策略**：直接引用 LazyLoading 源码（`<Compile Include="../Emuera/..." LinkBase="..." />`），而非复制到 xamarin 项目。这样保持与上游同步，避免代码分叉
- **Config.DefaultFont 委托**：Rikaichan.cs 中的 `Config.DefaultFont` 解析到 Platform Config（`MinorShift.Emuera.Config`），但 DefaultFont 定义在 Runtime Config。解决方案：在 Platform Config 添加 `DefaultFont` 属性委托到 Runtime Config
- **PressPrimitiveKey 参数类型**：从 `Keys` 改为 `int`，因为桌面端 KeyDown 事件直接传递 `e.KeyCode`（int 强转），避免对 System.Windows.Forms.Keys 的硬依赖
- **curLineY 初始化位置**：必须放在 `goto end` 之前，否则 rikaichan 代码在 `end:` 标签后使用未初始化变量
